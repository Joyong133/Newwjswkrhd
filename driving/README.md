# 🚗 VR 운전면허 연습장 — 맨손으로 운전 연습

메타 퀘스트(Quest 2 / 3 / 3S / Pro)용 **운전면허 연습 VR** 입니다. 퀘스트 브라우저에서 주소만 열면 바로 들어갑니다(WebXR, 설치·빌드 없음).
**핸드 트래킹(맨손)을 1순위로 설계**했습니다. 컨트롤러 없이 핸들을 쥐고 돌리고, 레버로 가속·브레이크를 하고, 손가락으로 버튼을 누릅니다.

## 할 수 있는 것

| 모드 | 내용 |
|---|---|
| 🚗 **기능시험** | 실제 장내 코스를 운전하며 자동 채점(100점 감점제, 80점 이상 합격) · 시험관 음성 안내 |
| 🛣 **자유 주행** | 채점 없이 같은 코스 연습 · 신호등 자동 순환 · 파란 가이드선 |
| 📝 **학과 연습** | 교통안전표지 · 신호·교차로 · 속도·고속도로 · 주정차·앞지르기 · 안전운전·차량관리 · 면허·벌점·응급조치 (66문제, 바로 해설) |
| 🧪 **모의고사** | 40문항, 1종(70점)·2종(60점) 합격 판정 |
| ❌ **오답노트** | 틀린 문제만 다시 풀기(맞히면 목록에서 빠짐) |

### 기능시험 코스
**출발(기기조작) → ① 차로준수 → ② 경사로 → ③ 직각주행 → ④ 신호교차로 → ⑤ 가속구간 → ⑥ 돌발상황 → ⑦ 종료**

- 기기조작: 시동 → 안전벨트 → 시험관이 지시하는 3가지(전조등·와이퍼·좌/우 방향지시등) → 기어 D 로 출발
- 차선(검지선) 접촉 −10, 코스 이탈 실격
- 경사로: 노란 정지 구간에서 멈춘 뒤 출발(정지 안 함 −10, 1 m 이상 뒤로 밀림 −10, 30초 초과 −10). 크리프·경사 중력이 구현되어 있어 실제처럼 뒤로 밀립니다
- 신호교차로: 적색 신호에 정지선을 넘으면 실격
- 가속구간: 구간 안에서 20 km/h 이상(미달 −10)
- 돌발: 경고음 → 2초 안에 정지(−10), 비상등(−10) → 비상등 끄고 출발
- 종료 구역에 멈추고 기어 P

> ⚠️ 연습용 앱입니다. 채점 세부 기준과 법령 요약은 실제 시험·최신 법령과 다를 수 있으니 도로교통공단 안내를 함께 확인하세요.

## 조작법

### 맨손(핸드 트래킹) — 추천
| 동작 | 방법 |
|---|---|
| 핸들 | 림(바깥 고리)을 **주먹 쥐듯 감싸거나**, **엄지·검지로 집어서** 돌리기. 양손 가능 |
| 가속 / 브레이크 | 운전석 오른쪽 **레버를 쥐고 앞으로 밀면 가속**, **몸 쪽으로 당기면 브레이크**, 놓으면 중립(D 에서는 천천히 굴러가는 크리프) |
| 버튼 | 시동 · 기어(P R N D) · 깜빡이 · 비상등 · 전조등 · 와이퍼 · 안전벨트 · 주차브레이크를 **손가락으로 꾹** |
| 메뉴 | 대시보드 **☰ 메뉴** 버튼 → 패널을 **손가락으로 직접 터치**(멀리서는 가리키고 집기) |
| 시야 맞춤 | 대시보드 **[자리 맞춤]** — 앉아서 정면을 보고 누르면 운전석 눈높이로 맞춰짐 |

### 컨트롤러
그립으로 핸들 잡기 · 오른 트리거 가속 · 왼 트리거 브레이크 · (핸들을 안 잡아도) 왼 스틱 조향, 오른 스틱 위/아래 가속/브레이크 · A/B/X/Y 메뉴

### 데스크톱(미리보기)
`↑↓←→`/`WASD` 운전 · `E` 시동 · `B` 벨트 · `1`~`4` 기어 P R N D · `Z`/`C` 깜빡이 · `X` 비상등 · `L` 전조등 · `I` 와이퍼 · `P` 주차브레이크 · `M` 메뉴 · 마우스 시점·클릭

### 편의 · 멀미 방지
- 회전·가감속 때 시야 가장자리를 어둡게 하는 **멀미 방지 비네트**(메뉴에서 끄기 가능)
- 앉아서 하는 것을 권장합니다. 어지러우면 바로 쉬세요

## 실행하기

이 폴더는 저장소 루트의 `vendor/three` 를 함께 쓰므로 **저장소 전체**를 호스팅하세요.

- **GitHub Pages**: Settings → Pages → 이 브랜치 `/ (root)` → `https://joyong133.github.io/Newwjswkrhd/driving/`
- **PC + USB**: 저장소 루트에서 `python3 -m http.server 8000` → `adb reverse tcp:8000 tcp:8000` → 퀘스트에서 `http://localhost:8000/driving/`
