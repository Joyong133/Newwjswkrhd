# ⚡ 전자공학과 VR 실험실 — 전자공학과의 밤

메타 퀘스트(Quest 2 / 3 / 3S / Pro)용 **몰입형 전자공학과 체험 VR**입니다.
앱 설치 없이 **퀘스트 브라우저에서 URL만 열면** 바로 VR로 들어갈 수 있어요(WebXR + Three.js).

## 실험 구성

| # | 실험 | 직접 하는 일 | 배우는 것 |
|---|------|------------|----------|
| 1 | **LED와 옴의 법칙** | 부품함에서 저항(10Ω·220Ω·1kΩ·10kΩ)을 골라 브레드보드에 꽂고, LED를 극성에 맞게 꽂은 뒤 전원공급기 노브로 전압 조절 | `I = (Vs − Vf) / R`, 저항 색띠 읽기, 다이오드 극성. 전류가 너무 크면 **LED가 '펑' 하고 타요** 💥 |
| 2 | **오실로스코프와 파형** | 함수발생기의 파형 버튼·FREQ·AMPL 노브를 돌려 화면의 분홍 점선(목표 파형) 3개와 일치시키기 | 주파수/주기(`T = 1/f`), Vpp, VOLTS/DIV·TIME/DIV, AUTO SET |
| 3 | **디지털 논리: 반가산기** | 74LS08(AND)·74LS32(OR)·74LS86(XOR)·74LS00(NAND) 칩을 소켓에 꽂고 입력 스위치 A/B를 바꿔 진리표 완성 | `S = A ⊕ B`, `C = A · B`, IC 노치(1번 핀) 방향 |
| 4 | **555 깜빡이 키트 납땜** | 인두 스테이션 예열 → 인두를 잡고 패드 10곳에 팁을 대서 납땜 → 보드가 뒤집히며 LED 교대 점멸 | 좋은 납땜 모양, 인두 안전(다른 손으로 팁을 만지면 "앗 뜨거워!") |
| ✎ | **보고서 제출** | 프린터에서 나온 보고서를 집어 조교석 제출함에 넣기 → 최종 학점(A+ ~ D+) | |

순서는 자유이며, 실수(LED 소손, IC 역삽입 등)와 소요 시간에 따라 학점이 매겨집니다.

### 몰입 요소
- 비 오는 창밖 야경(아파트 단지·교회 십자가), 가끔 치는 **번개와 천둥**, 깜빡이는 형광등 하나, 째깍거리는 시계

- 컨트롤러 **진동(햅틱)**: 노브 딸깍임, 부품 꽂기, 납땜 중 떨림, LED 소손
- 단톡방 메시지가 오는 **스마트폰** (집어서 읽을 수 있어요)
- 보고서를 제출하면 **비가 그치고 새벽이 밝아옵니다**

## 메타 퀘스트에서 실행하기

WebXR은 **HTTPS**(또는 `localhost`)에서만 동작합니다.

### 방법 1 — GitHub Pages (추천, 무료)
1. GitHub 저장소 → **Settings → Pages**
2. **Source: Deploy from a branch** → 브랜치 `claude/vr-electronics-experience-4b0wmp`(또는 병합한 `main`) / 폴더 **`/ (root)`** → Save
3. 1~2분 뒤 `https://joyong133.github.io/Newwjswkrhd/` 가 열립니다
4. 퀘스트를 쓰고 **Meta Quest 브라우저**에서 위 주소 접속 → **VR 시작 🥽**

### 방법 2 — PC에서 띄우고 USB로 연결
```bash
python3 -m http.server 8000          # 이 폴더에서 실행
adb reverse tcp:8000 tcp:8000        # 퀘스트를 USB로 연결(개발자 모드)
```
퀘스트 브라우저에서 `http://localhost:8000` 접속.

### 방법 3 — 아무 정적 호스팅
빌드 과정이 없는 순수 정적 사이트라서 폴더 전체를 Netlify / Vercel / Cloudflare Pages 등에 그대로 올려도 됩니다.

### 옵션
- `?q=low` — 그림자 끄기(가벼운 모드). 퀘스트 2/1은 자동으로 low
- `?q=high` — 그림자 켜기 강제

## 기술 구성

- **Three.js r186** (`vendor/three`에 포함 — CDN 의존 없음), ES 모듈 + import map, **빌드 도구 없음**
- 3D 모델·텍스처·사운드 파일 **0개**: 모든 형상은 코드로 모델링, 텍스처는 Canvas 2D로 그리고, 소리는 Web Audio로 합성
- 퀘스트 최적화: 정적 메시 병합(머티리얼별 + 정점 색 버킷) → 드로우콜 약 200, 정적 그림자맵 1회 렌더, 고정 포비에이션
- 컨트롤러/손 3D 모델은 WebXR Input Profiles(jsDelivr)에서 받아오며, 실패하면 대체 모델 표시

```
index.html            시작 화면 + import map
css/style.css
src/main.js           렌더러·루프·XR 세션·환경 연출(비/번개/새벽)
src/core/             입력(XR/핸드/데스크톱), 상호작용(잡기·노브·버튼·스냅), 이동, UI 패널, 합성 사운드, 파티클
src/world/            실험실 공간, 절차적 텍스처, 공용 모델/머티리얼
src/stations/         실험 1~4 + 조교석(보고서)
src/game/             미션 진행, 안내판/순간이동/손목 HUD/스마트폰
vendor/three/         Three.js (MIT)
```
