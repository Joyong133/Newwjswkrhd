# 🎓 전자공학과 VR 캠퍼스 — 4년 과정을 VR 로

메타 퀘스트(Quest 2 / 3 / 3S / Pro)용 **몰입형 전자공학 학습 공간**입니다.
앱 설치 없이 **퀘스트 브라우저에서 URL 만 열면** 바로 VR 로 들어갑니다(WebXR + Three.js, 빌드 과정 없음).

원형 캠퍼스 홀 중앙의 안내 데스크에서 출발해, 네 방향으로 펼쳐진 **1~4학년 전공관**을 돌며
과목마다 **📖 강의 → 🔬 3D 홀로그램 실습 → 📝 퀴즈(학점)** 순서로 공부합니다.
24과목을 모두 B 이상으로 이수하면 **졸업식**(축포 + 졸업장)이 열립니다.

## 메타 퀘스트에서 실행하기

WebXR 은 **HTTPS**(또는 `localhost`)에서만 동작합니다. 이 폴더는 저장소 루트의 `vendor/three` 를 함께 쓰므로 **저장소 전체**를 호스팅하세요.

### 방법 1 — GitHub Pages (추천, 무료)
1. GitHub 저장소 → **Settings → Pages**
2. **Source: Deploy from a branch** → 브랜치 선택(이 작업 브랜치 또는 병합한 `main`) / 폴더 **`/ (root)`** → Save
3. 1~2분 뒤 `https://joyong133.github.io/Newwjswkrhd/campus/` 가 열립니다
4. 퀘스트를 쓰고 **Meta Quest 브라우저**에서 위 주소 접속 → **VR 시작 🥽**

### 방법 2 — PC 에서 띄우고 USB 로 연결
```bash
python3 -m http.server 8000          # 저장소 루트에서 실행
adb reverse tcp:8000 tcp:8000        # 퀘스트를 USB 로 연결(개발자 모드)
```
퀘스트 브라우저에서 `http://localhost:8000/campus/` 접속.

## 구조

```
campus/
  index.html              시작 화면 + import map(../vendor/three)
  css/style.css
  src/main.js             렌더러 · XR 세션 · 메인 루프 · 알림 · 졸업 축포
  src/progress.js         진도 · 학점 · 설정 저장
  src/core/               입력(XR 컨트롤러/손, 데스크톱), 이동(스틱·스냅 회전·순간이동),
                          레이 상호작용, 캔버스 패널 UI, 합성 효과음 · 음성 읽기
  src/world/campus.js     원형 홀 · 하늘 · 바닥 학년 길 · 중앙 칩 홀로그램
  src/world/station.js    학년관: 과목 목록 · 강의 보드(강의/실습/퀴즈) · 홀로그램 실험대
  src/world/directory.js  중앙 안내 데스크 · 졸업장
  src/world/menu.js       빠른 메뉴
  src/content/year1~4.js  커리큘럼 데이터(강의 슬라이드 · 퀴즈)
  src/sims/y1~4.js        24개 실습(3D 홀로그램 + 그래프)
```

- 3D 모델·이미지·사운드 파일 0개: 형상은 코드로, 글자·그래프는 Canvas 2D 로, 효과음은 Web Audio 로 만듭니다.
- 컨트롤러/손 3D 모델은 WebXR Input Profiles(jsDelivr)에서 받아옵니다.
- 과목·강의·퀴즈를 추가하려면 `src/content/yearN.js` 에 항목을 넣고, 실습은 `src/sims/` 에 같은 형식으로 정의한 뒤 `sim` id 로 연결하면 됩니다.
- 디버깅: 브라우저 콘솔의 `window.__campus`
